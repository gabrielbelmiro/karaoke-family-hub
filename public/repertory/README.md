# Repertório local

Coloque aqui a sua pasta de repertório para o karaoke.

Estrutura recomendada:

```text
public/repertory/
  demo/
    manifest.json
    lyrics/
      minha-musica.lrc
    audio/
      minha-musica.mp3
```

O app aceita:
- `manifest.json` ou `repertory.json`
- Letras em `.lrc`
- Audio local opcional
